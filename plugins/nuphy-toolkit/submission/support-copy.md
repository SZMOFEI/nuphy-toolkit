## NuPhy Toolkit support

NuPhy Toolkit provides focused AI workflows for NuPhy teams. Its first Skill helps teammates clarify requests and draft Feishu-ready requirement entries and lightweight PRDs.

For help, include:

- the prompt you used, with confidential information removed;
- what you expected;
- what happened instead;
- the plugin version shown in the listing.

Contact: service@nuphy.com

The current release cannot edit code, publish site changes, write to Feishu, set project priority, or provide engineering estimates.
