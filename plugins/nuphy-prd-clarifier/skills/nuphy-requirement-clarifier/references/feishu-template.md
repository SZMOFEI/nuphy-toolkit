# 飞书需求池条目

**需求名称**  
一句话说明对象、动作和结果，不写技术方案。

**需求背景**  
业务触发、为什么现在提出、影响对象。

**遇到问题**  
当前现状、具体问题、已有证据。没有量化证据时明确写“目前为定性反馈”。

**期望结果**  
描述用户或运营最终能看到、完成或验证的变化。

**页面链接**  
逐行列出；无则写“未提供”。

**截图/附件说明**  
说明每份附件是什么；无则写“未提供”。

**期望上线时间**  
日期与业务原因；无则写“未提供”。

**验收标准**

1. 至少两条可独立验证的结果。
2. 覆盖关键设备、市场、语言或页面范围（如适用）。
3. 包含不得改变的关键行为（如适用）。

不要填写最终优先级、开发复杂度、负责人、版本号或技术方案。
