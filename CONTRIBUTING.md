# Contributing

Contributions that improve requirement clarity, reduce unnecessary questions, strengthen privacy boundaries, or add realistic test cases are welcome.

Before opening a pull request:

1. Keep the plugin limited to requirement clarification and PRD drafting.
2. Do not add credentials, customer data, private URLs, or confidential NuPhy material.
3. Keep facts, missing information, and assumptions separate in generated outputs.
4. Add or update a behavioral case in `plugins/nuphy-prd-clarifier/tests/test-cases.json`.
5. Validate the skill and plugin package using the OpenAI validators.
