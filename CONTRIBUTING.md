# Contributing

Contributions that improve an existing NuPhy workflow, strengthen privacy boundaries, or add realistic test cases are welcome.

Before opening a pull request:

1. Keep each capability in a focused Skill with a clear trigger, boundary, and test set.
2. Do not add credentials, customer data, private URLs, or confidential NuPhy material.
3. Keep facts, missing information, and assumptions separate in generated outputs.
4. Add or update the behavioral tests for the Skill being changed.
5. Validate the skill and plugin package using the OpenAI validators.

By contributing, you agree that your contribution is licensed under the MIT License.
