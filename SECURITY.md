# Security policy

## Supported version

Only the latest release is supported.

## Reporting a vulnerability

Do not include secrets, customer information, or private NuPhy business data in a public issue. Report security concerns privately to `service@nuphy.com` with the subject `NuPhy Toolkit security report`.

The current release is skills-only and has no authentication, remote server, analytics, or external write capability. Security reports should focus on unsafe instructions, unexpected data exposure, malicious bundled content, or installation integrity.
